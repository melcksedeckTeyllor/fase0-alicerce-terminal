# Projeto Fase 0 - Alicerce
Laboratório prático de estudos para desenvolver domínio sobre Git, GitHub, terminal, organização de projetos e boas práticas de desenvolvimento.

## 🎯 Sobre o projeto

Este repositório foi criado com o objetivo de consolidar conhecimentos fundamentais do ambiente de desenvolvimento, utilizando a prática como principal ferramenta de aprendizagem.

A proposta é estudar, experimentar comandos, executar exercícios e documentar os aprendizados relacionados ao terminal, Git, GitHub e estruturação de projetos.

Mais do que armazenar anotações, este repositório funciona como um ambiente de experimentação, onde cada conceito estudado será colocado em prática por meio de pequenos desafios e atividades.

## 🚀 Objetivos

- Desenvolver autonomia na utilização do terminal.
- Dominar o fluxo de versionamento com Git.
- Compreender branches, merges e resolução de conflitos.
- Aprender a trabalhar com repositórios remotos no GitHub.
- Aplicar boas práticas de versionamento e organização.
- Criar estruturas reutilizáveis para projetos futuros.
- Desenvolver familiaridade com ambientes virtuais e gerenciamento de dependências.
- Construir uma documentação técnica clara e organizada.

## 📚 Roadmap de estudos

### Semana 01 — Git, Terminal e Ambiente

**Objetivo:** dominar o fluxo básico do Git e desenvolver familiaridade com o terminal.

| Conteúdo              | Prática                                         |
| --------------------- | ----------------------------------------------- |
| Terminal              | Navegação, manipulação de arquivos e diretórios |
| Variáveis de ambiente | PATH e variáveis de ambiente                    |
| Git básico            | init, status, add, commit, log e diff           |
| Branches              | branch, switch, checkout e merge                |
| GitHub                | remote, push, pull, clone e Pull Requests       |
| Conflitos             | Simulação e resolução de conflitos              |
| Boas práticas         | .gitignore e proteção de dados sensíveis        |

### Semana 02 — Estrutura de Projeto e Perfil Profissional

**Objetivo:** construir uma estrutura de projeto reutilizável e organizar a presença profissional.

| Conteúdo           | Prática                                   |
| ------------------ | ----------------------------------------- |
| Ambientes virtuais | venv, pip e requirements.txt              |
| Organização        | src/, tests/, data/ e docs/               |
| Documentação       | README.md e .env.example                  |
| GitHub             | Organização do perfil e repositórios      |
| LinkedIn           | Posicionamento profissional               |
| Rotina             | Planejamento e acompanhamento dos estudos |

## 📌 Padrão de commits

Os commits seguirão o padrão Conventional Commits:


tipo(escopo): descrição objetiva

Principais tipos:
Tipo	Utilização
feat	Nova funcionalidade ou implementação
fix	Correção de erros
docs	Alterações na documentação
style	Formatação e ajustes visuais sem alterar lógica
refactor	Reestruturação de código
test	Inclusão ou alteração de testes
chore	Tarefas de manutenção e configuração
