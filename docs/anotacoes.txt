 Parte 1: Branches, Checkout/Switch e Merge
    Até o momento estava vendo somente a linha do tempo principal. Porém trabalhar em equipe exige trabalahr em paralelo no mesmo projeto sem que ocorra conflitos.
    Para isso temos a BRANCH que é uma ramificação, uma copia isolada da linha do tempo atual que nos permite atualizar e adicionar funcionalidades sem que a linha do tempo principal quebre.
    O comando para criar e ja entrar em uma nova branch - git checkout -b ou git switch -c. 
    Para que possamos trazer as atualizações feitas em uma branch usamos o MERGE, que é o ato de juntar uma branch na main(branch principal)
